## Known boundaries to keep explicit

- Trace redaction is a defensive baseline, not proof that arbitrary secrets can never appear.
- The 1.0/1.0 redaction result is only for the bundled synthetic adversarial fixture.
- Container replay uses Docker as an isolation boundary but does not claim Docker alone is a complete sandbox for hostile workloads.
- Base-image availability remains an external dependency when the required image is not already present locally.
- Reproduction success means the declared exit code/signature matched; it does not prove semantic equivalence of every environment detail.
