## Known boundaries to keep explicit

- A contract can only verify requirements that were actually encoded.
- Evidence provenance does not prove source authenticity without an external attestation mechanism.
- Command/pytest exit status proves only the observed process result, not that the selected check was sufficient.
- GitHub Actions runtime metadata is not a signed attestation from GitHub.
- Artifact and package-manifest hashes identify exact bytes but not producer trust or dependency safety.
- API-diff v0.7 detects removed OpenAPI path+method operations only; schema/parameter/semantic compatibility is out of scope.
- Freshness policy cannot prove that a chosen `max_age_seconds` is correct for the domain.
- Structured waivers must reflect explicit authorized decisions and must not be agent-invented.
